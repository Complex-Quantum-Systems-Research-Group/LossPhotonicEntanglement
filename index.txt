CORRECTED EP-MOKS REPOSITORY INDEX

Primary representation
- Two polarization qubits (one per sequential probe photon), not two bosonic occupation modes.
- Spin bath: finite XXZ spin-1/2 chain using S=sigma/2 convention.
- MOKE proxy: impulsive polarization rotation U=exp(-i theta sigma_y tensor M_z^probe).
- Default probe: nonuniform Gaussian-weighted local magnetization.
- Collective magnetization is an exact delay-independent/random-unitary control.

Files
- operators.py: tensor-product and Pauli helpers.
- hamiltonians.py: XXZ Hamiltonian, local/collective magnetization, Kerr and exchange generators.
- states.py: polarization Bell states and stable thermal spin states.
- new_evolution.py: unitary evolution primitives.
- new_protocol.py: sequential two-photon protocol.
- observables.py: partial traces and expectation values.
- measures.py: entropy, purity, mutual information, l1/relative-entropy coherence, concurrence, Bell fidelity.
- validation.py: density-matrix and unitarity assertions.
- pipeline.py: validation and sweep entry points.
- tests/test_physics.py: analytic/limiting-case tests.

Run before any expensive sweep:
  python pipeline.py validate
  pytest -q
